## 文档更新规范

### 1. 开发任务更新

**开始新任务时**:
```markdown
- [~] 2.2.1 实现上下滑动手势识别
```

**完成任务时**:
```markdown
- [x] 2.2.1 实现上下滑动手势识别
```

**任务阻塞时**:
```markdown
- [!] 2.2.1 实现上下滑动手势识别
```

### 2. 开发日志更新

**功能提交后**:
```markdown
### YYYY-MM-DD - vX.X.X

**功能名称**

#### 完成任务

- [x] 任务描述

#### 技术实现

- 实现细节说明

#### 相关文件

- 文件路径列表
```

**版本发布时**:
```markdown
## 版本历史

| 版本 | 日期 | 说明 |
|------|------|------|
| v0.1.0 | 2026-05-15 | MVP 版本 |
| v0.0.1 | 2026-05-01 | 项目初始化 |
```

### 3. Git 提交规范

**提交信息格式**:
```
<type>(<scope>): <subject>

<body>

<footer>
```

**示例**:
```
feat(card): 实现卡片上下滑动切换功能

- 添加手势识别
- 实现切换动画
- 添加预加载机制

Closes #123
```

## 文档检查

### Git 提交前自动检查

当执行 `git commit` 时，会自动检查：

1. **开发任务检查**
   - 检查提交涉及的任务是否已更新状态
   - 检查提交信息是否关联任务编号

2. **开发日志检查**
   - 检查功能提交是否已添加开发日志
   - 检查版本发布是否已更新版本历史

3. **文档一致性检查**
   - 检查任务与日志是否对应
   - 检查版本号是否一致

### 手动检查

```bash
# 检查任务状态
grep -c '\- \[x\]' docs/TASK.md
grep -c '\- \[~\]' docs/TASK.md
grep -c '\- \[ \]' docs/TASK.md

# 检查开发日志
grep -c '###' docs/DEVLOG.md
```
