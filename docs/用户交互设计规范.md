## 第一章：文档概述

### 1.1 文档目的

本文档是「冷知识星球」微信小程序的完整用户交互设计规范，旨在为产品经理、UI设计师、前端开发工程师提供统一的设计语言和交互标准。所有页面、组件、动效、色彩、字体、间距等设计要素均在此文档中明确定义，确保产品在视觉表现和交互体验上保持高度一致性。

### 1.2 关联PRD

本文档基于「冷知识星球」产品需求文档（PRD）编写，严格遵循PRD中定义的所有设计参数，包括但不限于：

- 色彩体系（主色、辅助色、中性色、状态色）
- 字体规范（字号层级、字重、行高）
- 间距与圆角规范
- 页面结构与导航体系
- 交互动效参数
- 组件状态定义

### 1.3 设计关键词

| 关键词 | 含义 |
|--------|------|
| **轻量** | 界面简洁克制，去除冗余装饰，让用户聚焦知识内容本身 |
| **清新** | 色彩明快不沉闷，留白充足，营造舒适的阅读氛围 |
| **探索** | 通过卡片滑动、AI互动等交互方式激发用户的好奇心和探索欲 |
| **温暖** | 色调柔和、文案亲切、动效自然，传递知识科普的温度感 |

### 1.4 适用范围

- 微信小程序端（iOS / Android）
- 设计稿制作（Figma / Sketch）
- 前端开发实现
- 设计走查与验收

## 第二章：设计原则

### 2.1 内容优先

知识内容是产品的核心价值。所有设计决策以内容展示为第一优先级，界面元素服务于内容的阅读与理解，避免装饰性元素喧宾夺主。

**实践要点：**
- 卡片区域占据页面最大视觉面积
- 文字排版注重可读性（行高、字号、对比度）
- 图片与文字保持合理的视觉层级
- 减少非必要的界面元素干扰

### 2.2 轻量交互

以最少的操作步骤完成用户目标，降低认知负荷，让用户在碎片时间内快速获取知识。

**实践要点：**
- 核心浏览仅需上下滑动，零学习成本
- 常用操作（收藏、分享）一步触达
- 减少弹窗打断，优先使用内联反馈
- 操作路径尽可能短

### 2.3 即时反馈

每一个用户操作都应有明确的视觉或动效反馈，让用户始终感知到系统的响应状态。

**实践要点：**
- 按钮点击有缩放动效（scale 1.0→0.9→1.0，200ms）
- 收藏操作有星星弹跳动效（scale 1.0→1.3→1.0，300ms）
- 卡片滑动有平滑过渡动画
- 网络请求有加载状态提示
- 操作结果通过Toast即时告知

### 2.4 一致性

相同功能在不同页面中保持相同的视觉表现和交互方式，建立用户的心智模型。

**实践要点：**
- 统一使用组件库中的标准组件
- 相同含义的颜色保持一致（如红色始终代表收藏/删除）
- 交互手势在全局保持统一
- 文案风格和语气保持一致

### 2.5 温暖感

通过柔和的色彩、友好的文案、自然的动效传递温暖的产品调性，让知识科普不再冰冷。

**实践要点：**
- 使用柔和的蓝色主色调，避免高饱和度的刺眼色彩
- 空状态使用插画和亲切的文案引导
- 打卡成功使用撒花/烟花庆祝动画
- 错误提示使用友好而非责备的语气

### 3.4 阴影规范

#### 3.4.1 阴影层级

| 层级 | 阴影参数 | 用途 |
|------|----------|------|
| S（轻阴影） | `0 2rpx 8rpx rgba(0, 0, 0, 0.06)` | 标签悬浮、轻量浮层 |
| M（中阴影） | `0 4rpx 16rpx rgba(0, 0, 0, 0.10)` | 卡片、弹窗、下拉面板 |
| L（重阴影） | `0 8rpx 32rpx rgba(0, 0, 0, 0.15)` | 底部弹出面板、模态弹窗 |

#### 3.4.2 阴影使用原则

1. 页面背景 ` #F5F5F5` 上使用 M 级阴影即可产生足够的层次感
2. 阴影颜色统一使用黑色透明度，不使用彩色阴影
3. 同一页面中阴影层级不超过2种，保持视觉统一
4. 列表中的卡片使用统一的阴影参数，避免大小不一

### 3.5 图标规范

#### 3.5.1 图标风格

- **风格**：线性图标（Line Icon），线条粗细 1.5px
- **圆角**：图标转角使用 1px 圆角，避免尖锐感
- **视觉重量**：与 28rpx 正文文字视觉重量匹配
- **来源**：优先使用微信官方 WeUI 图标库，不足部分自定义设计

#### 3.5.2 图标尺寸

| 尺寸 | 数值 | 用途 |
|------|------|------|
| XS | 28rpx | 标签内小图标、来源标注图标 |
| S | 32rpx | 列表项图标、按钮内图标 |
| M | 40rpx | TabBar图标、功能入口图标 |
| L | 48rpx | 空状态图标、功能说明图标 |
| XL | 64rpx | 装饰性图标、引导页图标 |

#### 3.5.3 图标颜色

- 默认态使用 ` #999999`，激活/选中态使用 ` #4A90D9`，强调场景使用 ` #333333`
- 功能色图标沿用对应功能色（如收藏 ` #FF6B6B`、AI ` #4A90D9`）

## 第四章：背景与纹理

### 4.1 页面背景色

所有页面统一使用 ` #F5F5F5` 浅灰背景，知识详情页使用 ` #FFFFFF` 白色背景以提供沉浸式阅读体验。

### 4.2 卡片背景

所有卡片统一使用 ` #FFFFFF` 白色背景，常规卡片搭配 M 级阴影，轻量卡片（类目入口、菜单）搭配 S 级阴影。打卡横幅根据状态使用 ` #FFF8E1`（未打卡）或 ` #E8F5E9`（已打卡）背景，无阴影。

### 4.3 微纹理与装饰元素

#### 4.3.1 页面装饰

- 首页顶部可添加极淡的星球/星空装饰图案（透明度 5%），呼应"星球"品牌概念
- 装饰图案使用 SVG 实现，确保清晰度和性能
- 装饰元素不得影响内容的可读性和可交互性

#### 4.3.2 卡片装饰

- 知识卡片保持纯净白底，不添加纹理
- 类目入口卡片可使用对应类目的主题色作为左边缘色条（4rpx 宽）
- 空状态区域可使用浅色插画填充

#### 4.3.3 个人中心头部

- 用户信息区使用主色 ` #4A90D9` 到深蓝 ` #2E6DB4` 的渐变背景
- 可叠加极淡的星球/星空纹理（透明度 8%）

## 第五章：动效规范

### 5.1 缓动曲线

| 曲线名称 | CSS 值 | 适用场景 |
|----------|--------|----------|
| ease-out | `cubic-bezier(0.0, 0.0, 0.2, 1.0)` | 卡片切换、页面转场、弹窗出现 |
| ease-in-out | `cubic-bezier(0.4, 0.0, 0.2, 1.0)` | 状态切换、颜色过渡 |
| spring | `cubic-bezier(0.34, 1.56, 0.64, 1.0)` | 收藏星星弹跳、按钮点击回弹 |
| linear | `linear` | 进度条、旋转动画 |

### 5.2 动效时长

| 时长等级 | 数值 | 适用场景 |
|----------|------|----------|
| 短（Short） | 150ms | 按钮点击反馈、颜色切换、图标旋转 |
| 中（Medium） | 300ms | 卡片切换、弹窗出现/消失、收藏动画 |
| 长（Long） | 500ms | 页面转场、底部面板滑入、复杂动画 |

### 5.3 全局动效规则

1. **同一页面最多同时运行 2 个动效**，避免视觉混乱和性能问题
2. 动效优先使用 `transform` 和 `opacity` 属性，确保 GPU 加速，避免触发重排（reflow）
3. 尊重用户的「减少动态效果」系统设置（`prefers-reduced-motion`）
4. 所有可交互元素的动效时长不超过 500ms，保持操作流畅感
5. 列表滚动使用原生滚动，不添加自定义滚动动效

### 5.4 核心动效参数

| 动效名称 | 参数 | 说明 |
|----------|------|------|
| 卡片切换 | 300ms ease-out, scale 1.0→0.95, opacity 1.0→0.8 | 当前卡片缩小淡出 |
| 新卡片进入 | 300ms ease-out, scale 1.05→1.0, opacity 0.8→1.0 | 新卡片从放大淡入 |
| 收藏动画 | 300ms spring, scale 1.0→1.3→1.0 | 星星弹跳效果 |
| 按钮点击 | 200ms spring, scale 1.0→0.9→1.0 | 按钮按下回弹 |
| 详情页进入 | 500ms ease-out, translateX(100%)→translateX(0) | 从右侧滑入 |
| AI面板滑入 | 500ms ease-out, translateY(100%)→translateY(0) | 从底部滑入，高度70%屏幕 |
| Toast显示 | 300ms ease-out, opacity 0→1, translateY(20rpx)→translateY(0) | 淡入上移 |
| Toast消失 | 300ms ease-in, opacity 1→0 | 淡出 |
| 打卡撒花 | 1000ms ease-out | 粒子从中心向四周扩散 |
| 骨架屏闪烁 | 1500ms linear, opacity 0.3→1.0→0.3 | 循环闪烁 |

## 第九章：适配规范

### 9.1 屏幕适配

#### 9.1.1 适配范围

| 设备 | 屏幕宽度 | 逻辑分辨率 |
|------|----------|------------|
| iPhone SE | 375pt | 320rpx |
| iPhone 12/13/14 | 390pt | 375rpx |
| iPhone 14 Pro | 393pt | 375rpx |
| iPhone 14 Pro Max | 430pt | 414rpx |
| iPhone 15 Pro Max | 430pt | 414rpx |
| Android 主流机型 | 360-412pt | 320-414rpx |

#### 9.1.2 适配策略

1. **rpx 单位**：所有尺寸使用 rpx 作为单位，微信小程序会自动根据屏幕宽度进行等比缩放（以 750rpx = 屏幕宽度为基准）
2. **最小宽度保障**：设计稿以 375pt（iPhone 12/13/14）为基准，确保在 320rpx（iPhone SE）上内容不溢出
3. **最大宽度限制**：内容区域最大宽度 750rpx，在平板等大屏设备上居中显示
4. **图片适配**：配图使用 `mode="widthFix"` 保持宽度自适应，高度按比例缩放
5. **文字适配**：使用 rpx 单位，确保在不同屏幕上等比缩放

#### 9.1.3 关键尺寸验证

| 元素 | iPhone SE (320rpx基准) | iPhone 14 (375rpx基准) | iPhone 15 Pro Max (414rpx基准) |
|------|------------------------|------------------------|-------------------------------|
| 页面外边距 | 32rpx | 32rpx | 32rpx |
| 卡片内边距 | 32rpx | 32rpx | 32rpx |
| 标题字号 | 32rpx | 32rpx | 32rpx |
| 正文字号 | 28rpx | 28rpx | 28rpx |
| 搜索框高度 | 72rpx | 72rpx | 72rpx |

### 9.2 安全区域适配

#### 9.2.1 顶部安全区域

- 使用微信小程序原生导航栏（`"navigationStyle": "default"`），自动适配刘海屏
- 自定义导航栏时，通过 `wx.getSystemInfoSync().statusBarHeight` 获取状态栏高度
- 导航栏高度 = 状态栏高度 + 44rpx（导航栏内容区）

#### 9.2.2 底部安全区域

| 元素 | 适配方式 |
|------|----------|
| TabBar | 使用微信原生 TabBar，自动适配底部安全区 |
| 固定底部操作栏 | 底部 padding 增加安全区高度（`env(safe-area-inset-bottom)`） |
| 底部弹出面板 | 底部 padding 增加安全区高度 |
| 固定底部按钮 | 距底部 = 48rpx + 安全区高度 |

#### 9.2.3 安全区获取方式

```javascript
const systemInfo = wx.getSystemInfoSync();
const safeAreaBottom = systemInfo.screenHeight - systemInfo.safeArea.bottom;
```

#### 9.2.4 横屏处理

- **不支持横屏**：在 `app.json` 中设置 `"pageOrientation": "portrait"`
- 锁定竖屏方向，确保交互体验一致性

### 9.3 特殊机型适配

#### 9.3.1 小屏机型（iPhone SE）

| 适配项 | 处理方式 |
|--------|----------|
| 知识卡片 | 描述文字最多显示3行，超出省略 |
| 类目筛选栏 | 始终可横向滚动 |
| 日历网格 | 日期格子适当缩小，最小 64rpx |
| 底部操作栏 | 紧凑布局，减少内边距 |

#### 9.3.2 大屏机型（iPhone 15 Pro Max）

| 适配项 | 处理方式 |
|--------|----------|
| 内容区域 | 最大宽度 750rpx，居中显示 |
| 卡片高度 | 内容自适应，不强制拉伸 |
| 日历网格 | 日期格子适当放大，最大 96rpx |

#### 9.3.3 刘海屏适配

- 页面内容不延伸到状态栏区域（使用原生导航栏）
- 自定义弹窗/面板的顶部内容距顶部 > 状态栏高度 + 16rpx
- 底部弹出面板内容区底部预留安全区
