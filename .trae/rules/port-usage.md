# 端口占用规则

## 规则说明

当尝试启动开发服务器时，如果目标端口已被占用，**不允许再次启动项目**，只需提醒用户当前端口正在运行中。

## 处理方式

### 1. 检测端口占用

在启动开发服务器前，先检测端口是否被占用：

```bash
# 检测单个端口
lsof -i :端口号 | grep LISTEN

# 检测多个端口
lsof -i :10086 -i :10087 -i :10088 -i :3000 | grep LISTEN
```

### 2. 端口占用时的处理

如果端口已被占用，**不要执行以下操作**：
- ❌ 自动 kill 占用端口的进程
- ❌ 强制重启服务
- ❌ 切换到其他端口继续运行

**正确的处理方式**：
- ✅ 提示用户当前端口正在运行中
- ✅ 显示占用端口的进程信息
- ✅ 告知用户如何手动处理（如需重启）

### 3. 提示信息模板

```
⚠️ 端口 {端口号} 已被占用，服务正在运行中

当前运行进程：
{进程信息}

如需重启，请先手动停止当前服务：
  kill {PID}

或清除所有 node 进程（谨慎使用）：
  pkill -9 node
```

## 常用端口

| 项目 | 默认端口 | 说明 |
|------|---------|------|
| app (Vite) | 5173 | React Web 前端 |
| app-taro (H5) | 10086 | Taro H5 开发服务器 |
| server | 3000 | NestJS 后端服务 |
| manage | 5174 | 管理后台前端 |

## 相关命令

```bash
# 查看端口占用
lsof -i :10086 | grep LISTEN

# 停止指定端口进程
kill -9 $(lsof -t -i:10086)

# 停止所有 node 进程（谨慎使用）
pkill -9 node
```
